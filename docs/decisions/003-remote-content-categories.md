# ADR-003：远程内容分类目录

日期：2026-10-30。状态：已采用。

知识选题库的分类属于知识内容领域，采用中文维基百科“主要话题分类”的 MediaWiki categorymembers 接口，而非国民经济行业分类。接口地址 https://zh.wikipedia.org/w/api.php ，接口说明 https://www.mediawiki.org/wiki/API:Categorymembers 。不需要 API Key，来源链接在页面展示。目录仍可能包含繁体字，现有“商业”等标签提供别名对齐。

后端 `/api/knowledge/meta` 按需获取分类，合并数据库已有分类与来源配置分类，确保历史资料仍可检索。远程分类为空或响应异常均视为失败；分页完整读取后再替换缓存，超过 5 页拒绝部分结果。过滤“主要话题条目”这一导航分类。远程目录不代表已有对应选题，不自动扩充文章来源。

采用进程内 24 小时缓存及锁避免同一进程并发重复请求，失败保留旧结果，5 分钟后重试。当前规模无需新增数据库表或迁移；代价是重启后需重新拉取、多进程各自同步、首次请求需等待网络。每个远程请求超时 4 秒。网络不可达时前端明确显示本地回退或旧缓存与上次成功时间，不将回退数据称作远程同步成功。后续规模扩大可把缓存迁到共享持久化存储。
