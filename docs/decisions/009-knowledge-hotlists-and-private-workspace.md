# ADR-009：知识细分标签、热搜快照及个人创作空间

日期：2026-10-31。状态：已采用，替代 ADR-005 中共享工作空间的设计。

分类与细分标签统一多选。细分目录由本地 279 个策划标签组成，覆盖热门与小众题材；远程 MediaWiki 分类目录继续保留，网络失败不影响本地标签。匹配是标题、摘要和来源分类的文本规则，不声称机器理解或实际热度。合并已有分类和标签选项时去重；多选 OR，其他条件 AND。

[60s 开源项目](https://github.com/vikiboss/60s) 及其[接口文档](https://docs.60s-api.viki.moe/)提供百度、微博、小红书等十个默认聚合来源；这些不是平台官方服务，公共实例存在限流。保留 [DailyHotApi](https://github.com/imsyy/DailyHotApi) 的 30 个停用备用模板，由管理员测试或换成自己的公开实例后启用。默认来源迁移只增量添加，保留已有编辑/停用/删除。2026-10-31 实测百度实际采集传输成功，小红书 HTTP 样例返回榜单但后续请求超时，微博返回 429；不能声称所有来源始终可用。

每个热搜源保存最后一次成功快照，含来源返回顺序、标题、链接、选题 ID、原始指标和采集时间。不同平台指标不合并比较；失败时保留成功快照，页面显示最后成功时间与错误。榜单对应选题写入知识库，支持收藏和创作，存储清理保护当前快照的选题 ID。

新增 dashboard_preferences 表，以 user_id 为主键保存首页卡片选择，访客仅使用浏览器本地存储。新增 personal_items.user_id / creation_cards.user_id，所有列表、单项读写都以登录用户 ID 过滤，管理员也不能读取其他账号的私人内容。唯一索引改为账号加目标，允许不同用户收藏/创作同一选题。

迁移把没有归属的旧共享资料交给最早创建的管理员；新用户看不到旧共享资料。MySQL 替换旧 topic_id 唯一索引前创建普通索引，维持外键要求。迁移前应备份；迁移后不能回退到不校验账号归属的旧版本，否则旧代码会把个人数据当共享数据读取。旧 SQLite 表的唯一约束重建不在生产迁移支持范围，离线测试使用新建 SQLite 表。
