# ADR-008：本地与生产 MySQL 直连

日期：2026-10-31。状态：已采用，替代 ADR-007 中的数据库 SSH 隧道方案。

本地开发与线上应用统一使用 MYSQL_HOST/MYSQL_PORT 直连数据库，用户指定地址为 152.136.228.231:3306。数据库账号、密码和库名延续现有配置。移除生产 tunnel 服务、依赖、镜像构建、密钥挂载及初始化脚本，生产 Compose 不再覆盖数据库地址。发布使用的 SSH 连接仍保留。

已部署的 shared/backend.env 不由发布脚本覆盖，升级前必须修改旧隧道地址。生产预检在暂停采集及迁移之前执行 SELECT 1，验证完整数据库连接；最终 up --remove-orphans 移除旧 tunnel 容器。回退通过旧版本 Compose 的默认服务集合启动，以兼容仍包含 tunnel 的历史版本；数据库连接环境文件不会自动回退。

应用日志预算变为 5 个常驻服务加 1 个临时迁移服务，共 600 MiB。数据库需要监听可达网卡，并为开发和生产来源配置账号授权及网络放行。连接凭据不进入发布日志。当前连接驱动没有强制配置 TLS，公网直连的传输加密需要另外配置服务器及驱动证书参数，不能将 SSH 加密属性视为仍然存在。
