# ADR-003：多渠道接口管理与知识融合

日期：2026-10-30。状态：已采用。

需求是拓展真实内容覆盖，并统一管理 API 和订阅接口。采用有界适配器：RSS/Atom、官方 Hacker News、Wikipedia 事件和通用公开 JSON GET。通用映射仅解释字段点路径，绝不执行表达式；继续复用既有公网传输约束。无需密钥的渠道优先接入，暂不建立敏感凭证管理。

URL 规范化去重不再使多个来源相互覆盖：主资料保持首次来源，其他发现渠道写入独立引用表，并保存社区投票与观测时间。发布日期未知保持 NULL，历史事件年份单独体现在标题中。不同站点不同 URL 的事件聚类仍留待后续实现。

接口 URL 可编辑，已有资料和引用随 source_key 一并迁移；保存 origin_key 标记初始化身份，使重新迁移不会恢复用户修改前的默认接口。删除使用 deleted_at，停用并隐藏，保留历史资料；显式新增同地址可以恢复。迁移增量导入新增默认渠道，不覆盖现有配置。

知识查询保留数据库 LIMIT/OFFSET 分页并返回完整分页元信息，支持每页数量、源过滤和稳定排序。来源引用批量查询，避免逐行访问数据库。首轮来源验证失败的百科默认停用，目录条目数、启用数、最近成功数分别表达，不制造可用性或热度。
