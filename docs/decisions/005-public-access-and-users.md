# ADR-005：公开访问与管理员账号

日期：2026-10-31。状态：已采用。

移除 Caddy 全站 Basic Auth，让资料库公开浏览。账号、角色与会话由应用管理，后端校验所有写入身份；来源配置、用户管理及手动采集要求管理员。普通账号可使用原有共享工作空间，暂不将已有收藏和创作数据拆成个人租户。

密码使用带随机盐的 PBKDF2-SHA256，随机会话 cookie 设置 HttpOnly、SameSite=Strict，HTTPS 下设置 Secure。数据库仅保存 token SHA256 摘要，会话 12 小时过期；账号编辑撤销会话，停用账号立即失效。同源检查继续防止跨站写入。登录采用单 API 进程内每 IP 五分钟十次限制，多副本时需在网关增加统一限流。

初始化与迁移从 ADMIN_USERNAME / ADMIN_PASSWORD 创建首个管理员，已有管理员不被配置覆盖，不提供默认密码或公开注册。用户不能停用自己或降低自己的管理员角色，防止失去管理入口。

左下角头像弹出菜单提供登录、退出、采集状态和管理员用户管理。管理员在采集状态页触发后台任务，复用原有 MySQL 互斥锁及半小时批次幂等，不影响定时 worker。API 重启可能丢失尚未完成的手动请求；此版本不引入持久任务队列，用户需根据状态记录重试。
