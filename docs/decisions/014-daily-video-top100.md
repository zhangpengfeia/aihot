# ADR-014：AI 影音热门前 100 每日更新

## 状态
已接受，2026-10-31。取代 ADR-013 的每周采集频率；影音与视频 Skill 识别范围保持。

## 决策
每天 Asia/Shanghai 时区 00:00 开始采集，完成后发布候选范围内累计 Star 前 100。菜单与页面称“热门项目”，不再称周榜。增长榜继续表示实际近 7 天增长，采集频率不改变增长指标口径。

成功批次按北京时间自然日去重，失败允许同日重试；启动后等下一个 00:00，不补跑、不重叠。保留 ai-video-weekly-v2 作为数据范围的兼容标识，不因调度更改排除已有相同范围的历史数据，无需数据库迁移。旧一周去重改为一天，确保次日能正常采集。

更新后需重启 GitHub worker 让新调度生效；make start 仍只启动前端与 API。并发互斥及失败保留上一期榜单沿用既有行为。
