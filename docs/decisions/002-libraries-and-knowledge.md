# ADR-002：Skill 库分类与知识资料采集

日期：2026-10-30。状态：已采用。

Skill 库作为父菜单统一管理项目资料、今日和历史热榜。每个项目使用最近快照构建资料库，用途标签来自 README/描述的多标签规则，安装信息摘录安装章节；历史快照保留原始资料，不执行原文指令。分类及安装信息随新快照保存，旧快照兼容读取。

知识采集独立进程与独立 MySQL 互斥锁，避免 GitHub 网络请求阻塞知识抓取。每个来源使用独立事务，记录最近尝试、最近成功和错误状态，成功窗口幂等。来源列表由环境配置提供，支持新增内容分类。初期仅采集公开 RSS/Atom 条目元数据与摘要，缺日期时保持 NULL。

不把时效性当作实际热度，不把历史题材当作已证实冷门。使用“热点候选/知识探索”表示选题用途；按发布日期排序，暂无阅读量评分。摘要是来源摘录，角度是规则模板并明确标注，不引入未经核实的模型事实。来源语言保留，中文翻译可后续接入模型服务。

知识按规范化 URL 去重，保留原来源，不把不同网站转载数量视为证据数量。未来需要事件聚类时应单独建立事件和引用表。

v0.2 提供显式可重入迁移：创建新表、添加两个可空字段；MySQL DDL 无法整体回滚，应先备份且单实例执行。测试采用可控 RSS/Atom、HTTP MockTransport 和隔离数据库验证解析、去重及单源失败隔离。MySQL 真正互斥锁另有可选集成测试。

国内/国外按题材关键词优先、来源默认地区兜底；保存 region_basis 使规则可解释。跨国涉及中国的话题优先归国内。旧资料只为能匹配配置的来源补地区，未知来源保留待分类。地区是检索标签而非事实结论；后续可加入人工修正，当前不自动推断复杂地缘范围。
