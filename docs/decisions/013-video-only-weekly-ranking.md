# ADR-013：默认周榜仅收录 AI 影音制作工具与视频 Skill

## 状态
已接受，2026-10-31。取代 ADR-010 中影音与办公合并的默认采集范围，其余周榜、历史与分析器约定保持。

## 决策
热门周榜服务于“热门工具及 Skill + 知识库选题 → 视频制作”。默认搜索聚焦视频生成、动画、数字人、剪辑、字幕、配音、音乐及视频 Skill，移除办公、表格、演示、会议等纯办公搜索。识别要求 AI 或 Skill 证据加影音能力标签同时成立，避免只修改搜索词却让已跟踪的纯办公项目再次入榜。项目兼具办公和影音能力时仍可收录。

继续按候选范围内累计 Star 排名前 100，每周一北京时间 00:00 更新，不足 100 时不虚构。使用 ai-video-weekly-v2 区分旧混合周榜，使当周旧范围成功批次不阻止新范围采集；默认榜单只返回新版范围，旧混合榜仅通过明确历史批次访问。首次新采集之前展示等待状态，不回退到旧办公混合榜。

核心功能、场景、知识内容方向建议及模型适配协议继续沿用，不在此变更中自动生成视频或新增模型调用。无新增字段，无需额外迁移；部署后重启 API/worker，再由管理员确认触发新采集即可。
