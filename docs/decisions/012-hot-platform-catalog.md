# ADR-012：平台目录与采集接口分离

日期：2026-10-31。状态：已采用。

参考图片逐项整理并去重，目录共 110 个平台（国内 70、国外 40）。百度、B站、北大未名等重复平台合并；即将上映电影、豆瓣电影、淘宝、淘宝·天猫等不同榜单入口分别保留。加入 YouTube、X、Reddit、TikTok、Instagram 等国外平台，但按用户要求本轮不为这些平台新增 API。

目录存于 app/core/hot_platforms.py，使用稳定 ID、展示名称、别名、分类和地区；目录预留不等于接口已连接。/api/knowledge/hotlists 保留旧 items 字段，附加 platforms，包含 reserved/configured 状态、实际来源、来源数和最后成功榜单。多个采集来源通过显式 platform_id、原名称或 origin_key 映射同一平台，改名后关联仍保留；目录外的管理员自建来源继续作为自定义平台展示，不做覆盖或删除。接口支持 region=国内/国外，前端地区筛选和平台搜索同时生效。

仅为百度、小红书补充 https://uapis.cn/api/v1/misc/hotboard?type=baidu 和 type=xiaohongshu，复用公开 API 受限传输、JSON 路径映射和热搜快照。依据服务方文档映射 list、hot_value、index；同原有 60s 来源并存。2026-10-31 真实验证两端点均成功解析 3 条，包含标题、原文 URL 和热度；验证只读，不写数据库。60s 小红书同轮测试成功、百度超时，不声称第三方接口始终可用。

验证覆盖图片平台完整性、去重、地区筛选、未知地区拒绝、预留平台不冒充数据、管理员改名保持平台关联、UAPI 字段映射。新增默认来源需通过迁移导入，不修改本地 make start 不采集的约定。

## 首页热搜卡片与独立热搜菜单

顶部分类、左侧平台、右侧榜单的布局仅应用于首页“全网热搜”卡片内部，保持整个首页原有卡片网格、编辑、拖拽、占行及统一高度。独立全网热搜菜单保持多平台卡片列表，不使用左右分栏的整页布局。

首页热搜卡片订阅存于 frontend/src/store/hotSearchCardStore.ts，按账号/访客本地持久化。首页卡片和热搜菜单的平台多选与知识库分类筛选共用 GroupedFilterPicker，按稳定平台 ID 筛选，支持国内/国外及内容类型分组、搜索、已选视图、清空、取消、应用。仅点击应用才修改生效条件，平台选项 OR，其他条件 AND。平台筛选不修改采集配置，不触发采集。

旧后端只返回 items 时，前端按原名称兼容合并平台；新后端 platforms 字段仍为权威目录。验证覆盖卡片作用范围、菜单卡片布局回退、知识库和平台共享多选交互，以及构建和状态缓存测试。
