# ADR-010：AI 影音与办公项目合并周榜及可替换分析器

## 状态
已接受，2026-10-31。取代 ADR-004 的 GitHub 每日调度与旧 Skills 采集范围。

## 决策
用户确认两类项目合并，以累计 Star 排序展示前 100，每周一北京时间 00:00 采集；同周成功后跳过，失败允许重试。每词从 GitHub 官方搜索 API 读取有限候选，默认总候选上限 500，加 200 个历史跟踪项目；榜单限定于成功观测并通过规则识别的候选，数量不足时不补齐，不能声称全网完整 Top 100。

保留历史数据，Run.scope 区分 ai-production-weekly-v1 和旧版本；自然周去重按 scope 和周时间范围查询，slot 保留实际观测批次时间，避免覆盖旧日榜。周增长使用约 7–8 天前实际观测，不从累计 Star 推算历史；旧 delta_24h 字段保留，新增 delta_7d 与独立基线。

快照增加 analysis JSON，保存核心功能、用途标签、场景、知识内容方向建议、证据及分析来源和版本。默认规则分析，UI 明示资料初判。旧快照保持未分析状态。通过 ProjectAnalyzer 协议和 ProjectAnalysis 数据契约替换模型实现，collect/persist 支持注入 analyzer；模型调用、密钥和重试策略留给后续适配器，不引入空转或隐含付费请求。

## 原因与影响
固定标签无法准确判断所有动画风格或真实功能，故展示规则证据并保留原文；未来模型输出也需校验且标注来源。建议不直接改写知识库分类，避免项目 README 的不可信文本改变用户配置。模型接入时应将 README 当作数据而非指令。

需先运行数据库迁移并重启 API/worker；历史增长字段保持兼容。GitHub 搜索有候选与限流约束；缺少一周历史时增长榜为空，累计榜可立即生成。
