# 来源管理与分类整理

沿用单用户共享实例，不引入账户、新外部服务或新依赖。

| 模块 | 责任 | 依赖 |
| --- | --- | --- |
| source-management | 数据库来源配置、添加/编辑/停用、限流测试、归属内容数 | 原有 RSS 采集与迁移 |
| category-management | 非破坏性别名合并/撤销、隐藏/恢复、有效分类筛选 | 原有内容及远程分类目录 |

实施：先新增模型与可重入迁移、来源配置读取，再完成来源管理纵向功能；随后增加分类规则和查询适配；最后后端测试、前端构建、隔离页面验证。

验收：导入默认/.env 来源，重新迁移不覆盖既有来源的停用及编辑状态；兼容工作目录中的增量默认来源导入；worker 每轮读取数据库启用列表，全部停用时不回退默认源。RSS 管理表单保留地址身份；兼容后端新增的地址编辑与统计归属迁移能力；新增源不要求先联网成功。测试只做预览，不写入选题，限制请求时长、2MB、50条；拒绝私网、凭证URL，逐跳验证并固定已校验IP，TLS保持主机校验。重复来源409，失败保留配置及历史内容。

分类以规则映射展示和筛选，保留原始分类；支持链式合并、拒绝循环，允许撤销别名；隐藏只移除筛选选项，不删除内容。下拉只显示合并后条数大于0且未隐藏的分类；管理页面可查看远程空分类和别名。详情、导出与看板显示一致。

验证：pytest 使用 SQLite 和可控网络；覆盖迁移重复运行、停用、全部停用、跨进程配置读取、归属计数、测试不入库、SSRF/重定向/大小限制、合并/撤销/隐藏/循环及分页过滤。前端 npm run build，浏览器验证管理页面与筛选行为。
