# ADR-004：GitHub 每日定时采集

日期：2026-10-30。状态：已采用。

GitHub 热门项目采集改为每天 Asia/Shanghai 时区 00:00 执行一次，替代 ADR-001 的半小时自动执行频率。worker 启动后等待下一个执行点，不立即采集、不补采错过的日期；运行失败等待下一次每日调度。每轮完成后计算未来的执行点，避免运行超时导致任务重叠。使用 UTC 计算等待时长，不依赖部署机器时区。

保留 `--once` 手动立即执行入口、原有半小时批次幂等和历史数据结构。知识采集继续独立按半小时运行。前端每分钟刷新只读取已保存结果。已有增长榜基线规则不变：数据不足或无法找到约 24–26 小时前的基线时显示缺失值。
