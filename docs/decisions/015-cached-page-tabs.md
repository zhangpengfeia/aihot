# ADR-015：内存页面缓存与顶部标签页

## 状态
已接受，2026-11-01。

## 决策
以 ViewKey 标识页面，首次访问时挂载，后续侧栏和顶部标签切换保留实例，只隐藏非当前页面。所有查询页面保留本地结果、筛选、分页和编辑草稿；避免只缓存 GET 响应却丢失 UI 状态。相同页面不会重复创建标签，首页常驻且不可关闭，关闭当前标签选择相邻页。

缓存仅在本次浏览器会话内生效：关闭标签卸载页面并释放数据，再打开重新查询；整页刷新也重新查询。按用户 ID 和角色为工作空间设置 key，登录、退出、切换账号或角色时清理所有页面实例，权限守卫保持生效。

useRefreshTick 感知 PageActivityContext，隐藏页停止自动刷新，重新显示时只重新开始计时，不立即查询。各页面使用独立 tick，手动刷新仅影响该页面。采集进度轮询在隐藏时跳过查询，服务端采集任务继续执行。正在请求的页面切换后允许完成并保存结果；关闭标签通过现有 effect 清理取消请求。

弹层通过页面内 ConfigProvider 绑定到对应缓存容器，避免隐藏页面的弹层漂浮在其它标签上。缓存不写 localStorage，不修改后端接口或永久保存个人查询数据。

## 验证
标签模型覆盖重复打开、关闭当前/后台标签、首页不可关闭与重开行为。前端构建通过；本地浏览器已验证顶部标签切换及搜索条件保留。
