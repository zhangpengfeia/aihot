# ADR-004：按领域和职责拆分前后端

日期：2026-10-30。状态：已采用。

单层目录使采集、API、配置和数据模型混在一起；前端入口超过 700 行，工作空间和知识管理页面集合超过 600 行。采用领域模块 + 公共基础设施组织方式，详细目录见 docs/architecture.md。

后端提取独立路由注册、请求 schema、模型包、领域服务、HTTP 客户端、运行入口与纯工具。共享时间和资料映射不再从 main 导入；来源配置不依赖服务包初始化，避免配置/模型/采集器循环加载。保留用户已使用的四个 Python 命令入口，Compose 改用 runtime 模块。

前端使用 app 组织应用壳、导航与主题；views 按 skills/knowledge/workspace 拆页，组件和 hooks 按复用范围放置。提取资源加载、日期格式和接口类型；管理表单、测试弹窗、知识表格和详情抽屉从页面移出。保持 React 和 Ant Design，不引入图片示例使用的 Vue，也不创建不存在的 chat/agents 业务。

本次仅整理代码：不改 API 路径、数据库表、采集周期或数据。通过既有业务测试、HTTP 方法/路径清单对照、兼容命令检查、TypeScript 和生产构建验证。样式按原级联顺序拆分，构建后的 CSS 内容保持一致。
