# 知识选题扩充与个人工作空间

- 分类和热门/小众标签合并为一个可搜索多选框，去重并按组展示；多选 OR，与地区、来源、时间、搜索等条件 AND，切换后回第一页。
- 279 个策划标签覆盖热门、技术、自然科学、人文冷知识、小众探索等题材，按标题/摘要文本证据匹配；标签不代表内容条数，不伪造阅读量。已有远程分类目录继续可用。
- 新增公开热搜聚合适配器，接入百度、微博、小红书等十组 60s 默认来源，另外提供 30 个 DailyHotApi 备用模板。备用模板默认停用，管理员测试后启用。来源增量导入，不覆盖手动修改和删除。
- 采集保存最后成功榜单顺序、来源指标和采集时间；失败保留历史榜单并显示错误，刷新页面只读数据库。本地 make start 不启动采集进程。
- 首页选择项目、知识库、热搜、收藏卡片；访客保存至当前浏览器，登录用户按账号保存至数据库，支持全隐藏。
- 收藏与个人备注移至创作者中心；访客不显示菜单，所有相关读写 API 必须登录并按当前账号过滤。跨账号卡片 ID 不可读取/修改/删除；收藏和创作唯一键包含账号。
- 迁移为旧共享收藏与创作补充归属，交给最早创建的管理员；不复制给其他账号。MySQL 迁移保留 topic_id 外键所需索引，可重复运行。

验证：真实路由跨账号读写测试、多选筛选去重/OR/其他条件 AND 测试、聚合响应异常与原始顺序测试、配置隔离测试、前端构建及格式检查。在线 API 可用性受网络及公共实例限流影响，不作为离线测试的成功前提。
