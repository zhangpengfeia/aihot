# ADR-007：服务器常驻采集与 GitHub 自动发布

日期：2026-10-30。状态：已采用（实际接入需服务器 SSH 凭据）。

生产入口为 zhangff.cn，目标服务器 root@152.136.228.231。使用独立生产 Compose，避免本地 `.env` 中 127.0.0.1:13306 的隧道地址被直接用于容器。新增独立 SSH 隧道容器，严格核验主机密钥，失联后退出重启；数据库转发端口仅存在于容器网络。现有两个 worker 常驻服务器，沿用北京时间每日 00:00 与每半小时计划，无需宿主机重复配置 cron。

GitHub Actions 在 main 推送时先验证再发布，PR 不接触生产凭据。固定 SHA 的 git archive 经 SSH 上传并检查 SHA256，服务器本地构建镜像，无须注册表账号。shared 目录保存服务器凭据、站点认证和配置，不随代码发布覆盖、不进入 Git。Caddy 负责 HTTPS、认证与入口日志，保留 Host 以支持现有同源写校验。

部署使用 flock 防重，先构建、再隧道和迁移、再健康检查，成功后切换 current 并保留 previous。失败尝试恢复上版应用；数据库 DDL、已写数据和历史清理不回滚。发布采用同一 Compose project，不承诺零停机；不删除其他应用容器，不执行全局镜像清理。

日志采取整个应用预算而非单容器 1 GB：7 个服务每容器 10 MiB × 10 份，合计 700 MiB，留出边界余量。程序、隧道、Caddy/Nginx 仅输出 stdout/stderr，由 Docker 轮转。临时迁移容器 --rm；部署脚本不保存服务器日志副本。部署后审计实际 logging 配置、运行服务及合计预算。范围不包括宿主机其他系统日志和外部数据库日志。

验证包含 Compose 配置解析、预算/端口暴露检查、ShellCheck、隔离日志审计/迁移失败回退测试、前后端现有检查。真实镜像启动、证书申请、隧道与公网健康验证需服务器凭据和有效 DNS 后完成。
