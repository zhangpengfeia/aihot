# ADR-011：首页卡片拖拽及 Zustand 本地缓存

日期：2026-10-31。状态：已采用。

首页编辑按钮与刷新按钮放在同一操作区。平时不显示拖拽、移除和新增控件；进入编辑模式后显示每张卡片右上角的拖拽手柄和 X，页面末尾提供新增卡片入口。X 只修改展示配置，不删除业务数据；新增仅列出尚未展示的卡片。完成编辑退出编辑模式，编辑模式本身不持久化。dnd-kit 提供指针和键盘排序，列表 DOM 顺序即用户配置顺序。

将旧 projects 分组拆为 overview/new_entries/risers/growth，知识库、热搜、收藏继续独立展示。旧后端配置和访客缓存自动展开 projects，顺序与全隐藏配置均保留；后端仍接受旧分组值，新增卡片枚举不涉及数据库结构变化。

Zustand persist 状态单独放在 frontend/src/store/dashboardStore.ts，以 guest/user:<id> 分隔缓存，持久化每个账号的 cards、revision、dirty。只存布局偏好，不缓存收藏正文、用户凭据或会话令牌。页面只负责编辑模式和拖拽事件，读取、写入及重试归 store 管理。

用户修改先写本地，随后串行 PUT 当前账号配置；请求期间的连续变更合并到下一次请求，避免响应顺序覆盖最新拖拽顺序。读取后端配置时检查 revision/dirty，慢速 GET 不覆盖新编辑。同步失败保留 dirty 与本地顺序，刷新、重新联网、窗口聚焦或点击重试时同步；切换账号后不再发送旧账号排队的请求。跨设备同时编辑采用最后提交的布局，暂不引入服务端布局版本冲突协议。

验证：store 测试覆盖本地恢复、旧值兼容、快速重排、慢速 GET、离线重试、账号切换；真实路由测试校验独立卡片顺序、空数组和账号隔离；浏览器验证进入/退出编辑、拖拽后刷新保留、移除后从底部重新添加。

## 整行/半行与统一高度

每张卡片独立保存 full/half 占行样式，Zustand 的 widths 与 cards 同一个 revision、同一次 PUT 同步。移除卡片不清掉宽度，重新添加仍保留原占行选择；旧缓存缺少 widths 时补默认值。后端继续使用原 JSON 列，旧数组兼容读取，新保存内容为 {cards, widths}；API 仍返回 cards 数组，附加 widths。旧客户端不发送 widths 时保留已有值，不需要新增数据库字段。

桌面为两列网格，full 跨两列、half 占一列，小于 1000px 自动单列，但不覆盖用户保存的宽度。拖动期间只修改临时顺序，真实 DOM 按卡片宽度实时重排；浮动预览不拉伸其他卡片，松手后保存一次，取消时恢复。所有卡片本体和占位统一为 360px，内容溢出时在卡片内滚动，概览也使用直接 Card 容器避免加载包装层导致高度不一致。

验证补充：宽度跟随排序/移除/重新添加、旧缓存补默认值、非法宽度拒绝及账号隔离；浏览器实测桌面混排/拖拽/刷新持久化，700px 视口自动整行，所有卡片和外层占位高度均为 360px。
